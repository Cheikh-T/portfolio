## 7. PROTOCOLE ANTI-FRAUDE IA & PÉDAGOGIE FRUGALE (RÉPONSE AUX ANGLES MORTS)

### A. Le Protocole Anti-Fraude IA : « Live Code Defense »
* **La règle des 3 minutes :** Tout projet donne lieu à une interrogation orale individuelle sur machine. L'enseignant demande à l'étudiant de modifier une condition ou de refactoriser une méthode en direct.
* **Barème de notation souverain :** 50% sur le dépôt GitHub + 50% sur la soutenance orale. Un code parfait généré par IA sans maîtrise orale vaut **0/20**.

### B. Pédagogie Frugale & Offline-First (Adaptée aux réalités locales de Bamako & Dakar)
* **Zéro dépendance aux émulateurs lourds :** Les cours Flutter et Mobile se compilent directement sur les smartphones Android des étudiants via câble USB (mode développeur ADB), évitant la saturation des PC (Core i3 / 4 Go RAM).
* **Mode hors-connexion :** Les bibliothèques et SDK (Maven, npm, pub cache, images Docker) sont fournis sur support local dès la première séance. Les coupures d'électricité ou d'internet n'interrompent jamais le cours.
